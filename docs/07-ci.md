# 07 · Integração contínua

Workflow: `.github/workflows/ci.yml`.

## Gatilhos

- `push` e `pull_request` para `main`.

## Passos

1. `actions/checkout@v4`.
2. `actions/setup-java@v4` com Temurin 21 e cache do Maven.
3. `./mvnw -B verify`: compila, roda os 24 testes (inclui Testcontainers, que usa o Docker do runner) e executa o `jacoco:check`.

## Cobertura

O plugin JaCoCo 0.8.12 falha o build se a cobertura de linhas do bundle ficar abaixo de `jacoco.minimum` (0.80 em `pom.xml`). O relatório fica em `target/site/jacoco/index.html`.

Medição da última execução local: cobertura de linhas de aproximadamente 95%.

## Limitações

- O workflow não tem etapa de publicação de imagem. A imagem Docker é construída localmente com `docker build`.
- O workflow ainda não foi executado no GitHub Actions; a validação real acontece no primeiro push.
